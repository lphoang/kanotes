# Kanotes

Hold the side button and Kapy, the Kanotes capybara, turns any screen into a calendar event or a note.
An Android app, made for Vietnamese chats first, that reads on your phone by default.

- **Download:** the latest signed APK is under [Releases](https://github.com/lphoang/kanotes/releases) (Android 12 or newer).
  Kanotes Cloud, the optional subscription, needs the Google Play version, coming soon.
- **More about Kanotes:** its page on my portfolio, under My apps → Kanotes.
- **Privacy policy:** on the same page, under "Read the privacy policy".

This repository only hosts releases; the app's source code is not public.
